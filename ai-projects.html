Four applied projects spanning retrieval, tool-using agents, transformer classification, and AI-security testing. Results and known limitations are reported alongside successful work.

Project 1 · RAG / Completed

The Unofficial Guide

Campus-life retrieval-augmented Q&A system.

  • Reworked fixed 800-character chunks into paragraph-based splits with 120-character minimum: 121 chunks averaging 230 characters.
  • Applied a 0.6 relevance cutoff to decline out-of-corpus questions.
  • Met all five evaluation criteria across three runs each, before and after an added grounding rule.
  • Documented a case that the grounding change fixed and another where it became overly cautious; manually corrected a misleading scorer verdict.

Tools: Python, ChromaDB, Gemini API, RAG

Project 2 · AI Agent / Completed

FitFindr

Agent that turns natural-language thrifting requests into a mock-listing outfit recommendation and caption.

  • Implemented search_listings, suggest_outfit, and create_fit_card tools with regex-based parsing.
  • Added trace.step() logging, model-unavailable error handling, and a documented tool exposed to external MCP callers.
  • Added synonym matching (e.g., pants → trousers), passing all five criteria before and after the change.
  • Known limitation: substring matching can falsely match “shirt” inside “sweatshirt.”

Tools: Python, agent tool calling, MCP

Project 3 · NLP / Evaluation Complete

TakeMeter

Three-class Reddit comment classifier: evidenced, speculation, or reaction.

  • Hand-reviewed 200 public r/TrueCrime comments (20 labeled cold; 180 AI-prelabeled then corrected).
  • Fine-tuned distilbert-base-uncased: accuracy 0.567 versus 0.400 baseline.
  • The model never predicted speculation: that class's F1 score was 0.000. Two of five criteria were missed.
  • Relabeling five samples did not improve performance; reported the non-improvement transparently.

Tools: Python, Hugging Face Transformers, DistilBERT

Project 4 · AI Security / Capstone In Progress

Provenance Guard

Experimental AI-text scoring service with submission and appeal workflow.

  • Developed a Flask service combining GPT-2 perplexity with a custom stylometric score and three-way output label.
  • Implemented /submit and /appeal endpoints plus structured audit logging.
  • Adversarial tests produced no crashes; malformed requests returned controlled HTTP 400 errors.
  • Raised the AI-label threshold from 0.70 to 0.80. Remaining work: fix a fake-appeal-ID bug by validating only status == "decided" log entries as proof of a submission.

Tools: Python, Flask, GPT-2, stylometry, API testing
