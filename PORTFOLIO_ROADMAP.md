Older programming repositories are retained to demonstrate progression in Python, C/C++, JavaScript, HTML/CSS, algorithms, and software-development fundamentals.

## Publication Standard

Before project materials are made public, they should be checked for:

- Credentials and API keys
- Personally identifiable information
- Employer/internal information
- Private infrastructure details
- Restricted coursework or answer keys
- Dataset licensing restrictions

Projects should include a clear README describing the objective, technologies, methodology, results, and skills demonstrated.
