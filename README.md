## Featured Cybersecurity Projects

### Forensic Recovery & Timeline Reconstruction
Digital forensics capstone using a NIST CFReDS forensic disk image and Kali Linux. The project combines file carving, metadata analysis, cryptographic hashing, and timeline reconstruction into a repeatable forensic workflow.

**Technologies:** Python, Kali Linux, Foremost, ExifTool, SHA-256, Matplotlib, ReportLab, NIST CFReDS

**Highlights:**
- Combined and validated forensic disk-image segments.
- Recovered deleted files with Foremost.
- Automated SHA-256 hashing and metadata extraction with Python.
- Produced structured timeline data and forensic reporting.
- Applied chain-of-custody, privacy, integrity, and investigation-scope principles.

### Phishing Attack Simulation & NLP-Based Detection
Team cybersecurity project exploring controlled phishing simulation and NLP/machine-learning approaches for identifying suspicious email and URL content.

**Technologies / Concepts:** Python, NLP, machine learning, SMTP, SPF, DKIM, DMARC, phishing awareness

**Highlights:**
- Designed a controlled phishing simulation methodology.
- Explored textual and URL indicators for phishing detection.
- Evaluated defensive controls including MFA, filtering, authentication protocols, and user education.

### Healthcare Security Assessment & Network Design
Security architecture assessment for a fictional healthcare environment, covering threat modeling, vulnerability assessment, segmentation, IAM, and security operations.

**Security Concepts:** VLAN segmentation, DMZ, ACLs, IDS/IPS, SIEM, MFA, Zero Trust, RBAC, PAM, incident response

**Highlights:**
- Identified attack vectors and prioritized security vulnerabilities.
- Designed segmented VLAN architecture separating administrative, employee, server, DMZ, and guest networks.
- Proposed least-privilege RBAC and privileged-access controls.
- Developed recommendations for centralized logging, SIEM, incident response, business continuity, and disaster recovery.
